About the project

This project puts WhatsApp and WeChat conversations behind a single inbox instead of two separate apps. Every connected contact — whether they message in on WhatsApp or WeChat — shows up in one sidebar, tagged with a small channel icon, so a support team can see and reply to everything without switching tools. It's built as a prototype for integrating both messaging APIs into a third party's existing business platform.

The problem

WhatsApp and WeChat don't share an inbox. A business that talks to customers on both ends up running two separate apps side by side, with conversation history split across platforms and no single place to see who's waiting on a reply.

Problem

  • Split inboxes. Agents juggle the native WhatsApp Business app and WeChat's own client separately.
  • Context switching. Moving between two apps per customer slows response time and risks missed messages.
  • No shared history. There's no single timeline of a customer relationship that spans both channels.

Solution

  • One inbox, both channels. Every contact appears in a single list, with a small icon marking WhatsApp or WeChat.
  • Real-time sync. Messages from either API land in the same thread view as soon as they arrive.
  • Consistent thread UI. Timestamps and bubbles render the same way regardless of source channel.

What I did

  • Integrated both APIs — WhatsApp Business API and WeChat's Official Account API — into one backend.
  • Built the webhook listeners that receive inbound messages from each provider and normalize them into a shared format.
  • Built the inbox UI shown here, including the per-conversation channel indicator.

How the integration works

WhatsApp and WeChat each have their own webhook format and their own API for sending messages back out. The integration layer's job is to hide that difference: both channels get normalized into one message model before anything reaches the database or the UI, so the rest of the app never has to know which provider a conversation came from.

Tech stack

Key features

The interface above is the agent-facing side of the integration — everything a support team needs to work both channels from one screen.

01Unified contact list

Every connected WhatsApp and WeChat contact appears in one sidebar, each marked with a small channel icon next to their number or ID.

02Real-time message sync

Inbound messages from either provider's webhook appear in the thread immediately, without a manual refresh.

03Company / contact search

A search bar over the contact list lets an agent jump straight to a specific client's thread.

04Consistent thread view

Message bubbles, timestamps and date dividers render the same way no matter which API the conversation came in on.
